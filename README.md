## 关注的方向

- **计算机系统**：操作系统、存储与缓存、并发机制，以及系统性能背后的取舍。
- **AI 基础设施**：LLM 推理、KV Cache 与上下文管理，关注效率与正确性如何兼顾。
- **Agent 工程**：工具执行、运行时状态与执行记录，探索可检查、可恢复的 Agent 系统。

## 正在做的项目

| 项目 | 在解决什么问题 |
| :--- | :--- |
| [**BearAgent**](https://github.com/CherryYang05/BearAgent) | 本地优先的 Agent Runtime，记录和检查工具执行过程，逐步探索可靠的恢复机制。 |
| [**myskills**](https://github.com/CherryYang05/myskills) | 整理自研与收录的 Agent Skills，把研究、开发和写作中的常用流程变成可复用的技能。 |
| [**Daily Planner**](https://github.com/CherryYang05/daily-planner) | 本地优先的任务与学习计划工作台，把计划拆成学习单元和可执行任务。 |

## 从底层开始

一些帮助我理解计算机如何工作的实践：

| 项目 | 实践内容 |
| :--- | :--- |
| [**LinuxKernel**](https://github.com/CherryYang05/LinuxKernel) | x86 32 位小型内核实践：多进程切换、内存管理、中断与简单图形界面。 |
| [**OpenMIPS_CPU**](https://github.com/CherryYang05/OpenMIPS_CPU) | 使用 Verilog 实现支持 89 条指令的五级流水 CPU，处理数据相关、流水线暂停和延迟槽。 |
| [**TCPIPImplementation**](https://github.com/CherryYang05/TCPIPImplementation) | 用 Java 实践 TCP/IP 协议及常见网络应用，理解数据从链路到应用的传递过程。 |
